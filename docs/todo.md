# Roadmap / TODO

## 当前状态

已完成：

- 单市场、单组合 TOML 配置
- 美股 / A 股免费行情 Provider 与 fallback
- SQLite 行情与资产目录缓存
- My Portfolio 卡片、搜索、收藏、目标权重
- Analysis：信息、K 线、回撤、目标配置、区间收益、权重漂移、资产贡献
- 动态 Analysis 卡片注册
- Lua 插件卡片（声明式 `text` / `metrics` / `table` / `line` / `bars`）
- 插件沙箱、超时、错误隔离

非目标 / 暂不做：

- 插件热重载（不需要）
- 盘中实时行情
- TUI 内交易、下单
- Windows 支持
- 多组合 / 多市场混合配置
- 跨币种收益换算

## P0：正确性与稳定性

- [ ] **补齐再平衡归因测试**
  - 覆盖 monthly / quarterly / yearly 再平衡日的资产贡献。
  - 验证 rebalance 当天使用目标权重，而非上一日实际权重。
  - 对比组合总收益与各资产贡献之和。

- [ ] **Provider 限流与重试**
  - 增加按 Provider 的最小请求间隔、指数退避和 429 处理。
  - 避免刷新全量目录或并发加载价格时触发免费源限流。
  - 在 UI 中区分“无数据”“限流”“网络失败”。

- [ ] **缓存 schema 版本与迁移**
  - 为 SQLite 增加 schema version。
  - 支持字段变更时的安全迁移。
  - 缓存损坏时给出明确修复路径，不删除用户配置。

- [ ] **配置兼容与迁移**
  - 检测旧多组合配置并提示，而不是只返回解析错误。
  - 提供可选的旧配置迁移命令或 TUI 提示。
  - 明确不会覆盖现有文件。

- [ ] **数据质量标记**
  - 在资产详情中显示复权口径、Provider、最后更新时间。
  - 标记过期缓存、缺失交易日和未复权数据。
  - 避免把回填/缺失价格静默当作真实收盘价。

- [ ] **终端尺寸回归测试**
  - 增加窄终端、低高度、宽终端渲染测试。
  - 防止卡片换行破坏布局。
  - 检查长资产名、长错误信息的截断。

- [ ] **插件 API 稳定性**

- [ ] **示例插件**
